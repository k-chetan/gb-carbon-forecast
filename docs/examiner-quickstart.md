# Examiner quick-start

1. Live app: <https://gb-carbon-forecast-go.streamlit.app/>. Free-tier apps
   sleep when idle; press the wake button and give it about 30 seconds.
2. The **Forecast** page shows the model's 48 h fan chart (p10/p50/p90) with
   the operator's forward curve dashed for comparison. The region dropdown
   shows operator forecasts only (there are no published regional actuals,
   so these are display-only and labelled as such).
3. The **Evaluation** page has the sealed 2025 horizon curves, the operator
   comparison in three labelled parts, and live counters from the weekly
   self-scoring job.
4. The **Model card** page lists data sources, licences, assumptions,
   limitations, and which model was evaluated vs which one is deployed.
5. Repository: <https://github.com/k-chetan/gb-carbon-forecast>. The badges
   at the top of the README show whether the pipeline is currently healthy.
6. Every number in the report can be regenerated from the repo:
   `make setup`, `make test`, `make report`.
7. The `vintage-log` branch holds NESO's forward forecasts captured hourly
   since 2026-11-21. Forecasts that were not saved at the time cannot be
   recovered later, which is why the logger exists.
8. The scheduled jobs live in `.github/workflows/` and their run history is
   public under the Actions tab.
9. The sealed 2025 test was scored once. `results/sealed/` is frozen and the
   evaluation script refuses to run a second time.
10. All figures are generated by `scripts/report_figures.py` from committed
    result files; none are pasted in by hand.
